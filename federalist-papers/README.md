# 연방주의자 논집 (The Federalist Papers) 한국어 번역

《연방주의자 논집》은 1787–1788년, 새 미국 헌법의 비준을 설득하기 위해 알렉산더 해밀턴(Alexander Hamilton), 제임스 매디슨(James Madison), 존 제이(John Jay)가 '푸블리우스(Publius)'라는 필명으로 쓴 85편의 글입니다. 이 폴더에서는 그 글들을 누구나 읽을 수 있는 쉬운 한국어로 옮깁니다.

- 원문 출처: [Project Gutenberg eBook #1404](https://www.gutenberg.org/ebooks/1404) "The Federalist Papers" (퍼블릭 도메인)
- 문체: 제1편은 부드러운 성경 같은 문체로, 제2편부터는 쉬운 현대 한국어(~합니다체)로 옮겼습니다.
- 용어: 모든 편에서 [용어집](glossary.md)의 번역어를 똑같이 따릅니다.
