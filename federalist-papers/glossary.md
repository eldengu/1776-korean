# 용어집 (Glossary) — 연방주의자 논집 한국어 번역

원칙: 쉬운 우리말을 먼저 쓰되, (편마다 문체가 달라도 용어는 같습니다) 논집 전체에서 거듭 나오는 핵심 용어는 아래 번역어로 **항상 똑같이** 옮깁니다. 문맥상 풀어 써야 할 때는 괄호로 원어나 표준 번역어를 함께 적습니다.

| English | 한국어 | 짧은 설명 |
|---|---|---|
| The Federalist (Papers) | 연방주의자 논집 | 책 제목. 각 글은 "제○편". |
| Publius | 푸블리우스 | 세 저자가 함께 쓴 필명. 음역만 합니다. |
| Union (the) | 연방 | 13개 주가 하나로 묶인 상태·나라. 논집의 중심어이므로 늘 "연방". 동사적 의미(뭉침)는 "하나로 뭉침"으로 풀어 씀. |
| union under one government | 하나의 정부 아래 하나로 뭉침 | Union(고유 개념)과 구별하기 위한 풀이. |
| federal | 연방의 / 연방 (관형) | "federal government" = 연방 정부. 1787년 당시 '현 연합 체제의 중앙 기구'도 federal로 불렸음에 유의. |
| confederation / the Confederation | 연합 / 연합 체제 | 연합규약(Articles of Confederation) 아래의 느슨한 국가연합. Union(연방)과 반드시 구별. |
| confederacy / partial confederacies | 연합 / 작은 연합(들), 따로 선 연합 | 13주가 몇 덩어리로 갈라져 만드는 지역 연합. |

| efficiency | 일을 잘함 / 효율 | 문맥에 따라 "일을 잘하는", "효율 있는". |
| republic | 공화국 | |

| democracy / pure democracy | 민주정 / 직접 민주정 | 매디슨(제10편)이 공화국과 구별하는 개념이므로 "민주주의"가 아닌 "민주정". |
| faction | 파벌 | 공익에 어긋나는 이익·감정으로 뭉친 무리(제10편). party와 구별. |
