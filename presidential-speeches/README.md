# 미국 대통령 연설 한국어 번역

미국 대통령들의 연설을 누구나 읽을 수 있는 쉬운 한국어로 옮깁니다. 각 연설은 두 가지 형태로 올립니다.

- **Markdown(.md)**: 문단마다 영어 원문을 인용으로 싣고, 그 아래에 한국어 번역을 붙였습니다.
- **HTML(.html)**: 영어 원문과 한국어 번역을 왼쪽·오른쪽으로 나란히 보여 줍니다.

영어 원문은 퍼블릭 도메인(public domain)이고, 한국어 번역은 저장소 루트의 [LICENSE](../LICENSE)에 따라 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)을 따릅니다.
